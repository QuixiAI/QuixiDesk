THIRD-PARTY NOTICES — accessibility typefaces bundled with claude.ai

This file covers the third-party typefaces that claude.ai offers in its
optional accessibility settings. OpenDyslexic and Atkinson Hyperlegible Next
are chat fonts, in Settings → General → Chat font. OpenDyslexic is also an
Interface font, in Settings → General or Settings → Claude Code → Appearance.
OpenDyslexic Mono is a Code font: Settings → Claude Code → Code font loads it
when that name is entered. claude.ai serves each typeface itself, and the
browser downloads one only when a font picker shows it or someone selects it.
The copyright notices and license terms follow. This file is not a complete
inventory of the third-party software or fonts used by the product.
