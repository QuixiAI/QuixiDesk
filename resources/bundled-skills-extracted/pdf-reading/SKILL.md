# PDF inspection

Original QuixiDesk task instructions.

1. Inventory the document and identify the pages relevant to the question. Distinguish page numbers printed on the document from file page indexes.

2. Extract text using available local tools. If the extraction order is unclear or content is graphical, render the relevant pages for inspection.

3. Use OCR for scanned text when an OCR tool is available. Treat OCR results as uncertain until checked against page images.

4. Preserve table units, footnotes, and column relationships. Cite the inspected pages in summaries.

5. Do not infer missing values or claim to have read pages that were not inspected.
