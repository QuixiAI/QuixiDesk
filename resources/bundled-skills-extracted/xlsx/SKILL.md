# Spreadsheets

Original QuixiDesk task instructions.

1. Identify the input workbooks, required sheets, units, and expected outputs. Preserve source data and work on a separate output file.

2. Inspect existing formulas and formats before editing. Use formulas for derived values, clear headers, and consistent number formats.

3. Keep dates as dates and numbers as numeric cells. Distinguish missing data from zero, and document assumptions near affected calculations.

4. Recalculate with an installed spreadsheet application when available. Check totals, references, error cells, and representative formulas independently.

5. Inspect print ranges and visible sheet layout for shared reports. State if formula evaluation or visual inspection remains unverified.
