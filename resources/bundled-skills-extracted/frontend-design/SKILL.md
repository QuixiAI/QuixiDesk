# Interface design

Original QuixiDesk task instructions.

1. Start with the users, their main task, and the information the interface must convey. Choose layouts and terminology specific to that product.

2. Create original layouts, icons, and copy. Use system fonts or dependencies with documented redistribution terms; retain required third-party notices.

3. Define a small spacing scale, readable typography, and accessible color pairs. Use semantic controls with labels, keyboard access, and visible focus.

4. Include loading, empty, error, and success states. Keep destructive actions clear and preserve entered data after recoverable failures.

5. Test narrow and wide layouts, long content, keyboard navigation, and representative user flows. Inspect screenshots and fix visible layout defects.
