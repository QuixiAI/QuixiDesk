# Presentations

Original QuixiDesk task instructions.

1. Clarify the audience, presentation purpose, desired slide count, and editable output format. Use supplied material as evidence.

2. Plan each slide around one message. Establish a consistent grid, type scale, color palette, and spacing before generating the deck.

3. Check installed presentation tools. Keep content editable where practical and preserve image aspect ratios. Give charts readable labels and units.

4. Open the resulting presentation and render all slides when a renderer is available. Check overlap, clipping, contrast, line breaks, and slide order.

5. Deliver the saved file and identify any rendering or compatibility checks that could not be completed.
