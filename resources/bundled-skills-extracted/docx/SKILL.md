# Word documents

Original QuixiDesk task instructions.

1. Identify the source files, audience, required sections, and output filename. Preserve the original documents when editing.

2. Check available document tools before choosing a workflow. Use named paragraph styles, real lists, and proper table structures instead of spacing text into columns.

3. Keep headings with their following paragraphs. Size tables and images to the page margins. Add alternative text to meaningful figures.

4. Validate the generated package, inspect its extracted text, and render pages with an installed office tool when available. Review page breaks and clipped content.

5. Report the saved path and the checks actually performed. If rendering is unavailable, state that visual layout remains unverified.
