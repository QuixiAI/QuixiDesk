# PDF editing and creation

Original QuixiDesk task instructions.

1. Determine the requested pages, edits, output path, and whether the source is scanned or contains selectable text.

2. Check installed PDF utilities and libraries. Work on a copy, preserve page dimensions unless requested otherwise, and keep page order explicit.

3. For new PDFs, use readable text sizes, consistent margins, embedded or system-available fonts, and accessible document structure where supported.

4. Reopen the output to verify its page count and text. Render affected pages and inspect cropping, rotation, image quality, and form appearance.

5. Keep private inputs local unless the user requests transmission. Describe any OCR or fidelity limitations in the result.
